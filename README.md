## What it does

`main.py` (Python 3.13, standard library only) writes one original line
roasting a smart fridge to `/output/entry.txt`. The roast targets the
fridge's firmware update locking its ice maker behind new terms — a
fresh angle on the smart fridge, not the usual grocery-ordering or
spying jokes.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
